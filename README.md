# 🌿 CareSkin: Ecossistema Inteligente para Dermatite Atópica

> Unindo vestuário terapêutico de alta performance térmica e tecnologia preditiva de saúde para melhorar a qualidade de vida de pacientes atópicos.

## 💡 Sobre o Projeto
A **CareSkin** nasceu para resolver uma dor crônica ignorada pela indústria têxtil tradicional: o sofrimento da pele sensível agravado por costuras ásperas, tecidos sintéticos e pelas ondas de calor extremo. 

Este repositório contém o código-fonte do **aplicativo móvel**, que atua como um ecossistema integrado:
* **Previsão Térmica Adaptativa:** Alerta o usuário em dias de calor e baixa umidade, recomendando o uso de malhas inteligentes respiráveis.
* **Diário de Gatilhos:** Monitora correlacionando alimentação, exercícios, roupas e crises de coceira.
* **Commerce Integrado:** Sugere diretamente as peças da marca adequadas para cada condição climática do dia.

## 🚀 Tecnologias Utilizadas
* **React Native / Expo** (Frontend Mobile)
* **JavaScript (ES6+)**
